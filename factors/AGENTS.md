# 因子研究规则

本目录用于构建 alpha factors。

---

# 1. 时间一致性

因子必须仅使用历史数据。

rolling 计算必须满足：

window 内数据发生时间 < 当前时间

示例：

正确：

20日收益率：
close.pct_change(20)

错误：

使用未来5日收益率排序

---

# 2. 不得混入交易逻辑

因子函数不应：

生成仓位
生成调仓日期
生成交易价格

只输出：

date
asset
factor_value

---

# 3. 因子处理步骤

应尽量拆分：

原始因子
winsorize
standardize
neutralize

避免：

在同一函数中混合多个处理步骤。

---

# 4. 因子评估建议

常用评估：

IC
rank IC
分层收益
换手率

避免仅依据单次回测判断因子有效性。

---

# 5. 数据注意事项

注意：

财报披露时间
停牌期间数据缺失
极端值
重复index

避免隐式填充未来数据。
